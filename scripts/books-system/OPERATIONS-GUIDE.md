|---------|------|
| 看进度（下一篇是谁） | `python publish_collection.py --status` |

| 发指定序号 | `python publish_collection.py 3` |

## 四、发布检查清单（每篇过一遍）

- [ ] `--status` 确认下一篇 seq 正确
- [ ] `next` 发布后，草稿箱出现新草稿
- [ ] 标题 ≤9 字、摘要 ≤17 字（品牌约束）
- [ ] 排版：深海蓝标题块 + 暖金引用 + ✦金句（自动）
- [ ] 封面：品牌封面 900×383（自动）
- [ ] 内容含「✦ 事上磨练」任务（每篇必须）
- [ ] `archive/` 出现对应快照（自动存档）
- [ ] 公众号后台把草稿归入「内心的修炼」合集

## 五、异常处理

| 情况 | 处理 |
|------|------|
| 发布 503/超时 | 脚本自动重试 5 次（指数退避），通常自愈；仍失败重跑 `next` |
| 翻译 503（生成文章时） | `translate_guide.py` 已带重试+断点续跑，重跑 `--all` 只补失败的 |
| 18001 代理长请求全挂 | 重启代理：杀 18001 端口进程 → `Start-Process python -u D:\zhaot\.workbuddy\multi_model_proxy.py` |
| 想重发某篇 | 手动把 `collection_plan.json` 里该 seq 的 `status` 改回 `"pending"`，再 `next` |
| 某篇译文不满意 | 改 `books/<书>/articles/XX.md` 后重发（存档记新版） |
| 想调整标题 | 改 `collection_titles.json`，重发即生效 |
