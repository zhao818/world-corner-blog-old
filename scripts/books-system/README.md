# 《内心的修炼》身心社财体系 · 落地方案（v2）

> 基于《塑造自己的言行——好人的生存学》框架重构。
> 五本书心性修炼 + 四层底座（经济·身体·心理·社会）= 完整生存系统。
> 每周 3 篇 · 每篇带事上磨练任务 · 边读边练边发文。

## 一、体系定位（v2 核心）

```
《塑造自己的言行》= 生存学外向篇（言说·行动·群众）
《内心的修炼》    = 生存学内向篇 + 底座篇（身心社财四层）
```

**四层闭环**：经济不稳 → 身体透支 → 心性失守 → 关系溃败。地基决定上层。

## 三、两种翻译模式

- **mode=text（原文拆章）**：叔本华/奥勒留 — 基于拆章原文翻译，含"原文精译"
- **mode=knowledge（AI 知识导读）**：传习录/萨特/福柯/身体/经济 — 基于核心思想生成，含"思想精要"

## 四、每篇标准结构

```

```
