# 公众号合集大纲 · 内心的修炼

> 五本书 = 一套完整的心性修炼体系。
> 从「断除噪音」到「看透规则」，34 篇，一条从外到内、再由内而外的成长弧线。

---

## 一、合集总览

**合集名**：内心的修炼
**定位**：不是哲学课，是一套用五本经典打磨心性的实操指南
**Slogan**：外断噪音 · 内立根本 · 事上磨练 · 果敢担当 · 明察规则
**篇数**：34 篇（5 阶段）
**节奏**：每周 3 篇（周一/三/五）

### 五阶段弧线

```
阶段一  断舍离   叔本华《人生的智慧》   → 过滤外界噪音，轻装上阵
阶段二  立根本   奥勒留《沉思录》       → 锻造内在城堡，稳住底盘
阶段三  炼心术   王阳明《传习录》       → 在事上磨练，知行合一 ★核心
阶段四  破执念   萨特《存在主义》       → 摆脱自欺，果断担当
阶段五  明规则   福柯《规训与惩罚》     → 看透权力规则，聪明地活
```
